# iOS/iPadOS Kiosk 模式设置指南

## 概述
本应用已内置kiosk防护功能来防止意外退出。但是,iOS/iPadOS系统级别的手势操作(比如从底部向上滑动退出)无法被应用程序完全阻止。

## 应用层保护(已实现)
应用提供以下保护:
- ✓ 阻止返回导航按钮
- ✓ 检测边缘滑动手势并显示警告
- ✓ 防止屏幕休眠(保持唤醒)
- ✓ 检测到退出手势时显示警告消息

## 完整Kiosk模式(需要设备配置)

要在iOS/iPadOS设备上实现完整的kiosk功能,您必须启用**引导式访问(Guided Access)**:

### 启用引导式访问

1. 在iPad/iPhone上打开**设置**
2. 进入**辅助功能** → **引导式访问**
3. **打开引导式访问**开关
4. 设置一个**密码**(退出引导式访问时需要使用)
5. 可选:启用**辅助功能快捷键**以便快速访问

### 使用引导式访问

1. 打开Worx Visitor应用
2. 导航到您想要锁定的kiosk页面
3. **三次按下侧边按钮**(或旧设备上的Home键)
4. 引导式访问界面出现
5. 配置选项:
   - 圈出需要禁用触控的区域(可选)
   - 如需要可禁用硬件按钮
6. 点击右上角的**开始**

设备现在已锁定到此应用和页面!

### 退出引导式访问

1. **三次按下侧边按钮**(或Home键)
2. 输入引导式访问密码
3. 点击左上角的**结束**

MDM允许您:

## 重要说明

⚠️ **应用无法强制启用引导式访问** - 必须手动启用或通过MDM配置

⚠️ **引导式访问密码非常重要** - 请妥善保存,否则可能需要恢复出厂设置

✓ **管理员登录** - 工作人员可以使用应用内的"管理员登录"选项退出kiosk模式

## 测试Kiosk模式

1. 按照上述说明启用引导式访问
2. 启动应用并导航到访客Kiosk页面
3. 激活引导式访问(三次按下)
4. 尝试:
   - 从底部向上滑动(应该被阻止)
   - 从边缘滑动(应该被阻止)
   - 使用硬件按钮(如果已配置应该被阻止)

## 故障排除

**问:用户仍然可以退出应用**
- 答:确保引导式访问已启用并激活(检查屏幕顶部是否有橙色条)

**问:忘记了引导式访问密码**
- 答:您需要重置设备或联系IT管理员

**问:应用显示警告但用户仍可退出**
- 答:这是正常的,没有引导式访问的话。警告只是提示作用。

**问:需要在引导式访问模式下更新应用**
- 答:先退出引导式访问,更新应用后再重新启用引导式访问

## 当前应用保护的工作原理

即使没有启用引导式访问,应用也会:

1. **检测边缘手势** - 当用户从屏幕边缘滑动时显示警告
2. **检测底部上滑** - 当用户从屏幕底部向上滑动时显示警告
3. **阻止返回导航** - 阻止使用返回按钮退出
4. **节流警告** - 每3秒最多显示一次警告,避免骚扰

但是,iOS系统级的退出手势仍然有效,只是会看到警告提示。要完全阻止这些手势,必须启用引导式访问。
