# Android Kiosk 模式设置指南

## 概述
本应用已内置kiosk防护功能来防止意外退出。但是，Android系统级别的导航操作(返回键、主页键、最近应用)无法被应用程序完全阻止，需要设备级别的配置。

## 应用层保护(已实现)
应用提供以下保护:
- ✓ 阻止返回键并显示警告消息
- ✓ 沉浸式模式隐藏导航栏
- ✓ 防止屏幕休眠(保持唤醒)
- ✓ 检测到退出尝试时显示警告消息

## 完整Kiosk模式(需要设备配置)

要在Android设备上实现完整的kiosk功能，您必须启用**屏幕固定**(消费级设备)或**锁定任务模式**(企业设备):

---

## 方案1: 屏幕固定(消费级设备)

### 启用屏幕固定

1. 在Android设备上打开**设置**
2. 进入**安全** → **高级** → **屏幕固定**
   - 位置可能不同: **设置** → **锁屏** → **屏幕固定**
   - 或: **设置** → **应用** → **屏幕固定**
3. **打开屏幕固定**开关
4. 可选: 启用**"取消固定前需要输入PIN码"**以增强安全性

### 使用屏幕固定

1. 打开Worx Visitor应用
2. 导航到您想要锁定的kiosk页面
3. 打开**最近应用**(方块按钮或向上滑动手势)
4. 找到Worx Visitor应用卡片
5. 点击卡片顶部的**应用图标**
6. 从菜单中选择**"固定"**

设备现在已锁定到此应用!

### 退出屏幕固定

**未设置PIN时:**
- 同时按住**返回键 + 最近应用键** 2-3秒
- 或使用手势导航时向上滑动并按住

**设置PIN时:**
- 相同手势，然后输入您的PIN码

---

## 方案2: 锁定任务模式(企业/MDM)

适用于已注册Android Enterprise或设备所有者模式的企业部署:

### 前提条件
- 设备已注册到Android Enterprise
- 应用设置为设备所有者或配置文件所有者
- 已配置MDM解决方案(EMM)

### 通过MDM配置

大多数MDM解决方案(AirWatch、MobileIron、Microsoft Intune等)都支持锁定任务模式:

1. 在MDM控制台中创建kiosk配置文件
2. 将Worx Visitor应用添加到允许的应用列表
3. 启用**锁定任务模式**或**Kiosk模式**
4. 将配置推送到目标设备
5. 启动应用时将自动进入kiosk模式

### 手动锁定任务模式(开发/测试)

用于开发目的，可以使用ADB:

```bash
# 启用设备所有者模式(需要恢复出厂设置)
adb shell dpm set-device-owner com.example.worxvisitorapp/.AdminReceiver

# 将应用列入锁定任务模式白名单
adb shell settings put global lock_to_app_enabled 1

# 为特定activity启动锁定任务模式
adb shell am start-lock-task com.example.worxvisitorapp/.MainActivity
```

**注意:** 设置设备所有者在大多数设备上需要恢复出厂设置。

## 方案3: 第三方Kiosk启动器

使用Google Play上的专用kiosk启动器应用:

### 推荐的启动器:
1. **Fully Kiosk Browser & App Lockdown**(热门选择)
   - 提供免费版
   - 功能丰富
   - 带Web管理面板

2. **SureLock Kiosk Lockdown**(企业级)
   - 专业kiosk解决方案
   - 远程管理
   - 支持多应用kiosk

3. **Hexnode Kiosk Lockdown**(MDM集成)
   - 云端管理
   - 单应用或多应用kiosk
   - 最多25台设备免费

### 使用Kiosk启动器设置:
1. 从Play Store安装kiosk启动器
2. 配置启动器仅允许Worx Visitor应用
3. 将启动器设置为默认主屏应用
4. 在启动器设置中配置退出密码/PIN

| 功能 | 屏幕固定 | 锁定任务模式 | Kiosk启动器 |

| 需要恢复出厂设置 | 否 | 通常需要 | 否 |
| 远程管理 | 否 | 是(通过MDM) | 是(付费版) |

## 故障排除

**问: 用户仍可使用返回键退出**
- 答: 如果屏幕固定处于活动状态，第一次返回显示警告，第二次返回将取消固定(如未设置PIN)
- 解决: 在屏幕固定设置中启用"取消固定前需要输入PIN码"

**问: 在设置中找不到屏幕固定**
- 答: 位置因制造商而异。尝试在设置搜索栏中搜索"固定"

**问: 需要在kiosk模式下更新应用**
- 答: 先退出kiosk模式，更新应用后再重新进入kiosk模式

**问: 设备重启后退出kiosk模式**
- 答: 这是屏幕固定的正常行为。要持久化kiosk，请使用锁定任务模式或kiosk启动器

**问: 底部导航栏仍然可见**
- 答: 应用使用沉浸式粘性模式。从边缘滑动会暂时显示导航栏，但会自动隐藏

**问: 用户可以通过通知栏访问设置**
- 答: 屏幕固定应该阻止此操作。如果没有，请确保已正确启用且设备是较新的Android版本

## 安全最佳实践

1. **启用取消固定PIN** - 防止未经授权的退出
2. **禁用通知访问** - 防止用户通过通知访问设置
3. **企业使用MDM** - 集中管理和安全策略
4. **定期安全更新** - 保持Android OS和应用更新
5. **物理安全** - 如在公共区域，使用支架或外壳固定设备
6. **网络限制** - 使用防火墙/MDM限制网络访问仅访问必需的服务

## 管理员登录(应用内退出)

工作人员可以使用应用内置的"管理员登录"功能退出kiosk模式:
1. 点击kiosk界面中的"管理员登录"按钮
2. 输入管理员密码
3. 应用导航到仪表板(退出kiosk)

无论屏幕固定/锁定任务模式状态如何，此功能都可使用。

## 当前应用保护的工作原理

即使没有启用屏幕固定或锁定任务模式，应用也会:

1. **阻止返回按钮** - 使用PopScope拦截返回键并显示警告
2. **沉浸式模式** - 自动隐藏系统导航栏和状态栏
3. **保持屏幕唤醒** - 防止设备休眠
4. **生命周期监控** - 当应用恢复时重新应用沉浸式模式

但是，系统级的退出操作(主页键、最近应用)仍然有效。要完全阻止这些操作，必须使用屏幕固定、锁定任务模式或kiosk启动器。

---

## 总结

| 需求 | 解决方案 |
|-----|---------|
| 快速测试/演示 | 屏幕固定(不设PIN) |
| 单台kiosk设备 | 屏幕固定配合PIN |
| 多台设备 | Kiosk启动器应用 |
| 企业部署 | 通过MDM的锁定任务模式 |
| 最高安全性 | 锁定任务模式 + MDM + 物理安全 |

⚠️ **重要**: 应用无法强制启用系统级kiosk模式。需要设备配置才能完全锁定。
